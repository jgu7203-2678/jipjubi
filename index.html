안녕하세요! 어느 지역의 청약을 찾으세요? 실제 모집공고를 함께 찾아볼게요.

🗺️ 전국 청약 공고 찾기

청약홈 분양정보 API에서 모집공고를 조회합니다.
서버 연결 확인 중
검색 조건을 선택하고 공고 검색을 눌러주세요.
API 키가 연결되면 실제 청약홈 모집공고가 표시됩니다.
공고 정보는 한국부동산원 청약홈 제공 데이터 기준입니다. 청약 자격, 접수 일정, 공급금액은 반드시 입주자모집공고 원문과 청약홈에서 최종 확인하세요.

🏢 아파트 실거래가 조회

국토교통부 실거래가 API를 이용해 지역·계약월별 매매 신고자료를 조회합니다.
법정동 코드와 계약년월을 입력하면 실제 신고된 매매 내역을 조회합니다.
실거래가는 신고 자료이며 정정·해제 등으로 변동될 수 있습니다. 5자리 법정동 코드는 행정표준코드관리시스템에서 확인하세요.

📍 청약 분양가 · 반경 1km 시세 비교

청약 단지 주소를 좌표로 변환하고, 주변 아파트 실거래를 거리와 3.3㎡당 가격으로 비교합니다.
청약 단지 주소와 분양가, 전용면적 및 지역 정보를 입력하면 주변 실거래가 비교를 시작합니다.
비교 결과는 입력한 법정동 코드와 계약월의 국토교통부 신고자료를 바탕으로 산출합니다. 거리 계산은 브이월드 주소 좌표 변환이 정상 응답하는 경우에만 표시됩니다. 동일 면적·동일 조건 비교가 아니므로 투자 판단의 단독 근거로 사용하지 마세요.

집줍이 이용 안내

실제 데이터 기반으로 청약 정보를 확인하는 서비스입니다.

1. 청약 공고 검색

지역과 공고 기간을 선택해 전국 모집공고를 조회합니다.

2. 청약 일정 확인

공고일, 접수 기간, 당첨자 발표 등 제공되는 항목을 확인합니다.

3. 실거래가 비교

법정동 코드와 계약월을 입력해 거래 흐름을 살펴봅니다.
현재 버전은 공고 검색과 실거래가 조회를 위한 기본 서비스입니다. 반경 1km 자동 비교, 평당가 분석, 청약 경쟁률 연계는 다음 단계에서 추가합니다.
